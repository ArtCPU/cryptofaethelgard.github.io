# cryptofaethelgard.github.io
Jogo para o PMO de 29/08
Feito com Gemini 3.7 Flash

O prompt inicial usado foi: "Create a text adventure game with code containing complete structure (HTML, CSS and logic in JavaScript) so that it can be played directly from the web browser"

Os primeiros outputs vieram bugados, completamente não funcionais. Depois de mais alguns prompts apontando o tipo de erro (Parte do código sendo tratado como texto, formatação incorreta/incompatível, etc) a IA conseguiu criar um código funcional para o jogo, mas era muito pequeno e sua estética era simples. Com o passar de 10 iterações (sem contar o conserto de bugs iniciais), fui expandindo o jogo, mexendo na dificuldade e deixando a UI e o esquema de cores mais compatível com os temas do jogo

Fora os bugs iniciais, não teve problemas na criação do jogo
